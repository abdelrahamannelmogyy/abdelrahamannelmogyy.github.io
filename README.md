## How it is built

Plain HTML, CSS and JavaScript, with no framework and no build step, hosted on GitHub Pages. Fonts are self-hosted, and there are no third-party scripts or trackers. The motion respects reduced-motion and data-saver settings, and every section works without JavaScript and prints cleanly.

The `tools/` folder holds the checks run before every change (layout from 320 to 1920 px, accessibility with axe, Lighthouse, keyboard, print, the contact form and the animations). See `tools/README.md`.
